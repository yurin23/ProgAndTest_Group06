Project: Student Attendance System
Guidelines for group projects

1. Project Requirements

Students are required to work in groups to analyze, design, implement, and test a software application. The project must follow the four stages below.

     Stage 1 – Analysis and Requirements Specification

·       Describe functional and non-functional requirements using natural language.

·       Draw a Data Flow Diagram (DFD), Use Case Diagram, and Class Diagram.

Stage 2 – Design

·       GUI Design: Design the graphical user interface.

·       Software Architecture Design: Apply an appropriate architecture or design pattern studied in the course.

·       Database Design: Define tables, attributes, primary keys, foreign keys, and relationships, where applicable.

Stage 3 – Implementation

·       Use programming languages such as Python / C++ / Java.

·       Apply an appropriate software architecture studied in the course.

·       Organize the source code clearly and use version control.

      Stage 4 – Testing

·       Create and execute test cases, perform unit testing, debugging, and manage identified defects.

3. Suggested Tools

Document, source code, and team management: GitHub / GitLab
Drawing DFD, Use Case, Class Diagram, and Database Schema: https://app.diagrams.net/
GUI design: Figma
Programming IDEs: VS Code / Visual Studio / PyCharm / Eclipse / …
Creating test cases: Excel
Unit testing: pytest (Python) / Google Test (C++) / JUnit (Java)
Bug tracking tools: Jira / Bugzilla / Mantis Bug Tracker
Packaging and deployment: Docker
Other tools may also be used.
